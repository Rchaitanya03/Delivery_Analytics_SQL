- LAST MILE DElIVERY OPERATIONS ANALYTICS

1) The objective of this project is to design and implement a Last Mile Delivery Operations Analytics system that efficiently stores, manages, and analyzes delivery-related data. 

2) The system tracks various aspects of delivery operations, including customer information, orders, drivers, vehicles, delivery assignments, delivery status, delivery duration, and delivery performance. 

3) The system ensures the integrity and consistency of data by using relational tables with appropriate primary keys and foreign key relationships between customers, orders, drivers, vehicles, and deliveries. 

4) The system enables meaningful analysis of delivery operations by providing insights into delivery demand across zones, customer ordering behavior, delivery performance, driver utilization, and vehicle performance.
 
5)The goal is to support the Operations team in making data-driven decisions, improving resource utilization, identifying delivery issues, optimizing operational performance, and enhancing the overall efficiency of last-mile delivery operations.
